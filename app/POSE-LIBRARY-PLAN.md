# 原版小女孩体式库

人物唯一标准：用户第一版小女孩。2026-10-19 用户拒绝了程序重画的新人物；新矢量人物已停用。禁止用更换人物来填补图库缺口。

`pose-library.json` 已登记现有24张原版素材，绑定同一个角色ID与每张图片的SHA256指纹。图库登记不代表24张动作全部通过专业核验。

## 建库与调用

1. 知识条目：中英文/梵文名称、动作别名、支撑点、手臂、腿部、躯干、左右、变体、参考页面、核验记录。
2. 人物母版：固定脸型、发型、服装、配色、身体比例、线条与视角规范，直接使用用户原版人物参考。
3. 素材条目：每个具体变体有独立poseId和固定assetId，不把不同手臂、膝盖落地/抬起混为一图。新增图需同时通过人物一致性和动作形态复核才入库。
4. 网站识别视频中的形态与变体，映射poseId，再调用固定素材。打印/下载复用同一文件，不在每次输出时重新画人物。
5. 无匹配时加入待补图清单；不能用相近但错误的动作或其他人物代替。未知姿态仍需保留待确认，不冒充完成。

优先根据当前课程实际缺失的高频动作补充，再逐步扩展。站姿、坐姿、跪姿、四点支撑、俯卧、仰卧、平衡等分族登记；不宣称一次覆盖所有瑜伽流派与变体。
