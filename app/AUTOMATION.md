# 自动处理程序

入口：根目录“打开瑜序.cmd”，或已启动的 http://127.0.0.1:8787/ 。Node.js和FFmpeg已在当前电脑配置。复制到其他电脑时需另行安装，当前不是免安装分发包。

## 实现

- 输入 MP4 / WebM 视频文件，最多1 GB、90分钟。本地流式写盘，不把整段原视频放在内存。
- FFmpeg验证真实时长及可解码性；每60秒切片，压缩最长边至约960像素、12fps、无声MP4。
- qwen3-vl-plus以2fps读取视频片段，输出动作时间和身体结构。使用原有账号，必须确认该模型的免费额度保护；不自动切换模型。
- 基于身体结构匹配原版插画，名称不决定插画。未覆盖的变体显示缺图；unknown左右明确保留，并去掉未经确认的左右口令。
- 跨片段仅合并连续保持的同一动作，保留返回动作。模型把多个动作合为一条时，最多重新提取一次；仍不合格则失败。不会因网络错误无限重试。
- 结果和逐段模型输出持久保存在 runtime/jobs，24小时过期；压缩片段随处理清理，原视频成功后删除，失败时保留供恢复。服务重启后，已完成结果可读取，中断任务可继续；已完成片段直接复用。浏览器最近预览保存在本地存储中。
- 前端自动轮询进度并进入预览，可导出PNG、SVG和打印。超过150项时禁止单张PNG，使用SVG或分页打印。
- 服务只监听本机，拒绝跨站和非localhost Host；不提供密钥或任意文件读取路由。

## 当前限制

输出为自动生成草稿。结构检查、重复提取和形态规则无法证明模型没有漏动作或识别错误。插画为原版图库参考，仍需专业姿态核验；缺图没有接入绘图服务，不能宣称全体式覆盖。没有音频识别。长课程有代码支持，但尚未完成完整20分钟课程验收。

小红书完整分享链接已接入；B站仍可能无法取得公开播放数据。视频直链仅允许配置的精确来源域名，不跟随重定向。此限制不因做成自动程序而消失。

默认处理会发往百炼。程序不查询实际剩余额度或账单，云端“免费额度用完即停”是费用边界。每段最多两次提取；60分钟课程最多120次调用，通常只有一次/段，仍以实际额度限制为准。

## 检查

`npm test` 包含形态匹配、左右未知、时间检查、复合动作拒绝、跨段合并、重启恢复和隔离模型的上传全流程测试。真实浏览器验收记录另见 runtime/jobs 对应结果；不把模拟测试称为真实模型效果验证。
