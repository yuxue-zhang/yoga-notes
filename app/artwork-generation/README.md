# 原版小女孩插画资产

角色固定为用户第一版的棕色丸子头女孩、淡紫背心、灰绿长裤。

- 保留24张原版图，不覆盖原文件。
- 使用内置image_gen（不使用第三方额度接口）制作104个新体式的同人物插画，保存到 `app/dist/assets/`。
- 图集01为16个基础体式；02–07为其余88个体式；08是目视检查后重画的8个变体，正式映射覆盖对应旧格。
- 每个体式用固定角色ID、固定图集、固定格号。页面和每次输出复用同一张图，不在使用时临时再画人。
- 原版素材指纹在pose-library.json；新增图集指纹在character-assets.json。
- `atlas-plan.json` 保存格子顺序；`prompts.json` 保存02–08的实际生成提示词；三个原版人物参考在character-reference目录。图集01的任务是山式、展臂、幻椅、战士二、战士一、三角、侧角、树式、手杖、坐姿前屈、船式、狮身人面、桥、挺尸、骆驼、站立前屈，按4×4排列。

人物一致性经过目视比对。插画是体式候选稿，不宣称经过专业瑜伽教师逐项核验；尤其扭转方向、手脚接触与进阶体式仍应核对。此批工作不恢复视频分析。

生成/登记维护顺序：运行 `register-atlases.mjs`，再运行 `../build-pose-catalog.mjs`。这些是开发维护步骤，用户无需运行。
