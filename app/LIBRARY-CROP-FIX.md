# 动作库图片边界修复（2026-10-20）

已在 codex/pose-library 独立 worktree 修复并集成至主目录。

已检查8张源图集，并逐页查看全部128个动作的实际网页；8页截图保存于主目录 app/runtime/library-fixed-page-1.png 至 -8.png。55项测试通过，含104个边界合法性、严格遮罩及浏览器登记同步检查。重新登记图集时，仅在文件哈希及格子位置相同时保留已审核 bounds，防止后续登记覆盖修复。

主目录服务无需重启，静态页面已使用修复。视频任务保持暂停。
