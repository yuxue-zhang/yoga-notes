# 瑜序本地开发版

需要 Node.js 22+，无第三方依赖。运行 `./start.ps1`，打开 http://127.0.0.1:8787 。

## 百炼配置

复制 `.env.example` 为 `.env`，仅在本机填写 API Key 和业务空间 ID，不发送到聊天。北京地域 `qwen3-vl-plus` 必须有剩余免费额度，且控制台“免费额度用完即停”已生效，才能将 `BAILIAN_FREE_QUOTA_CONFIRMED` 设置为 `true` 并重启服务。此变量仅为人工确认声明，不能查询或替代云端计费保护。

首轮限制 MP4 / WebM、12 MB、2 分钟。直链域名须在 `VIDEO_ALLOWED_HOSTS` 中精确允许。B 站等网页链接尚未支持。

## 能力与边界

- 已连接视频提交、百炼请求、任务轮询、结构检查、图库匹配和预览导出。未配置时在上传前停止。
- 仅画面识别，没有语音识别。模型自报完整及结构检查均不能证明动作无遗漏。左右和体式仍需对照真实视频验证。
- 原版图库按体式名称精确匹配，尚未验证变体及左右朝向；缺图保留占位，不调用绘图服务。
- 单任务处理，不自动重试或切换模型。记录返回 token 用量，不查询费用或剩余额度。
- 视频只在本机内存中临时处理并发往百炼，不写入本地磁盘；百炼侧保留规则需后续确认。结果在内存保留一小时，重启清空；浏览器保存最近预览。
- 仅监听本机；没有多人身份隔离、持久任务、服务端视频时长核验，不适合直接公开部署。
- 未真实调用模型，未做浏览器端到端或打印实测。原线上站点与原离线版未修改。

## 验证及下一步

`npm test` 覆盖错序、左右证据、来源限制、免费额度配置保护和本地接口。
`node --check dist/app.js` 与 `node --check dist/api.js` 检查前端语法。

下一步配置模型及免费额度保护，使用允许分析的短视频逐项验证，再扩展语音、完整课程和缺图生成。

接口依据：[百炼视频理解](https://help.aliyun.com/zh/model-studio/vision)、[免费额度与用完即停](https://help.aliyun.com/en/model-studio/new-free-quota)。2026-10-18 核对，实际账号接口仍需调用验证。
