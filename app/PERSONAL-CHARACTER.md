# 专属人物（可选功能）

网站主流程仍为课程转练习提示贴纸。独立入口 `/character`，默认使用手绘人物，不提供多画风选择，不要求用户确认人物后才能生成。

## 实现

- `personal-character.mjs`：本机人物记录、单次生成锁、失败接续、按人物版本缓存体式。使用用户已连接的 `api.openai-next.com/v1`，读取完整模型名单，再调用 `/images/edits`，明确要求 `response_format=b64_json`。不把 Key、照片数据或网关原始错误回传浏览器。
- 原照片仅用于建立人物；成功后删除本机上传副本。失败时保留副本便于续接，页面可以删除整个人物。用户桌面原文件不会被修改。
- 人物照片单独作为母版参考。动作生成由浏览器把固定母版放在左侧、动作库参考图放在右侧，合成一张标明角色的参考板，避免部分兼容网关只处理多张参考图中的最后一张。
- 换装新建人物版本，旧版保留；体式缓存不跨人物版本复用。当前换装为白色交叉领短袖上衣、紫色宽松灯笼裤；默认协调手绘比例约4.5头身，身体同样简化。
- `dist/personal.js`：照片上传、人物列表、三个体式样张、换装、预览样张、图片内嵌导出。上传照片不自动生成课程动作；当前仅手动生成三个样张。
- 专属样张在独立弹窗预览与下载；标准预览与打印始终使用原版小女孩，不修改课程状态。

## 限制

这是单用户本机开发版，没有在线多用户账户隔离。生成图需要目视检查人物和动作，不能保证生图模型完全不偏离参考，不宣称经过专业体式审核。

课程体式映射沿用现有名称/原图索引匹配，无法映射时保留待确认。专属形象功能不代表此前60分钟课程的识别已经完成。

## 验证

`node --test`：54项通过（含照片格式限制、参考图编辑、缓存、失败恢复、换装隔离、路径校验、同源 API 和图片下载）。真实照片已验证编辑接口能返回并保存 PNG；生成效果以最终样张检查为准。
